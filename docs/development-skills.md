# SPECTRE Development

Este repositorio incluye skills locales del proyecto en `.agents/skills/`:

- `spectre-plan`: preparación de planes a partir de un alcance confirmado.
- `spectre-execute`: ejecución de planes y verificación de cambios.
- `spectre-feature-root`: inicializador interno de raíz de feature.

Son instrucciones de desarrollo del proyecto y no forman parte del bundle de la aplicación. Se incorporaron para que el trabajo futuro en este repositorio pueda usar el flujo SPECTRE disponible en el entorno Codex. La distribución contiene estas tres skills; los flujos que dependan de otros componentes SPECTRE deben configurarse en el entorno antes de invocarlos.
